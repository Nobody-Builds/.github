# .github

The Nobody Builds organisation profile, shown at [github.com/Nobody-Builds](https://github.com/Nobody-Builds) from `profile/README.md`.

The banners in `profile/assets/` are generated from [Nobody-Builds-Design](https://github.com/Nobody-Builds/Nobody-Builds-Design):

```bash
pip install Pillow fontTools brotli
python scripts/build-banners.py path/to/Nobody-Builds-Design
```
